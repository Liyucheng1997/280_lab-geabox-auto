为什么需要换挡？

内燃机只在 800 – 6500 rpm 的窄转速带内工作，最大扭矩只有一个峰值点； 而车轮需要的转速从 0 到上千 rpm、需要的扭矩从起步的几千 N·m 到巡航的几百 N·m。 变速箱就是扭矩与转速的“变换器”——用不同齿比把发动机的窄工作带映射到车轮的全部需求区间。

发动机外特性曲线

全油门下的扭矩(蓝)与功率(橙)。注意：低转扭矩弱、超过红线断油。

驱动力 – 车速图（换挡的根本原因）

每个挡位只能覆盖一小段车速；虚线是行驶阻力。曲线在阻力线以上才能加速。 五条曲线拼起来才近似理想的恒功率双曲线。

发动机转速 – 车速关系

同一车速下，挡位越低发动机转速越高。阴影为可用转速带：车速提高后低挡会“顶到红线”，必须升挡。

三个实验： ① 直接挂 5 挡起步 → 驱动力低于阻力，发动机被拖到熄火转速； ② 一直用 1 挡 → 55 km/h 就顶到红线断油； ③ 正常逐挡升挡 → 每次换挡都是把发动机“拉回”扭矩带。

小结

  • 发动机不能从 0 转：起步必须靠离合器滑摩把 0 rpm 的车轮和 ≥800 rpm 的发动机接起来。
  • 低速需要大扭矩：1 挡总减速比 ≈ 14，扭矩放大 14 倍，轮上驱动力才够克服起步阻力。
  • 高速需要高转速：若没有 5 挡（超速挡），120 km/h 巡航发动机会转得又快又费油。
  • 挡位数越多，越能让发动机停留在高效率区——这也是 8AT/10AT 与 CVT 出现的原因。

手动换挡的完整过程

场景为纵置后驱布局的剖视：发动机曲轴 → 飞轮 → 离合器 → 输入轴 → 中间轴 → 输出轴（同步器换挡）→ 传动轴 → 后桥。 点击下方播放，观看 2 挡升 3 挡的每一个机械动作。

换挡七步（2 挡 → 3 挡）

    转速匹配（同步器在做什么）

    绿色 = 输出轴上的接合套转速（由车速决定）；蓝色 = 3 挡齿轮的接合齿转速（由输入轴决定）。 两者相等的瞬间，接合套才能无冲击地滑入。

    离合器状态

    离合踏板
    0%
    压盘夹紧力
    100%
    可传扭矩
    100%

    踩下踏板 → 分离轴承推动膜片弹簧内端 → 杠杆作用使压盘后移 ≈2 mm → 从动盘悬空，动力路径断开。

    同步器原理（黄铜环的秘密）

    • 换挡时目标齿轮的转速 ≠ 输出轴转速，硬推会打齿。
    • 接合套先推动黄铜同步环压在齿轮的锥面上，靠锥面摩擦把齿轮拖到同步转速。
    • 未同步时，同步环偏转半个齿距锁止接合套（打不进去）；同步完成摩擦力矩消失，环回位，套筒滑过接合齿完成换挡。
    • 离合器踩到底是为了切断发动机惯量——同步器只需同步几个齿轮的小惯量，几百毫秒即可完成。

    自动挡如何自动换挡

    AT 用液力变矩器替代离合器（起步永不熄火），用行星齿轮组 + 多片离合器/制动器替代同步器换挡， 由 TCU 按“车速 × 油门”查换挡图自动决定何时换。

    TCU 换挡图（换挡决策的核心）

    实线 = 升挡线，虚线 = 降挡线（两者间距为迟滞区，防止来回跳挡）。 油门越深，升挡点越晚——这就是“地板油降挡”的原理。

    液力变矩器特性

    速比=涡轮转速/泵轮转速。起步时速比≈0，扭矩被放大近 2 倍；高速时锁止离合器闭合，效率≈100%。

    行星齿轮原理演示

    固定/驱动不同构件即可得到不同速比——不用移动任何齿轮，换挡只是切换“谁被刹住”。
