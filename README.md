# 汽车换挡原理 Three.js 交互演示

这是一个面向教学展示的浏览器端机械仿真，包含三个可切换模块：

- **为什么需要换挡**：自由选择挡位与油门，观察发动机转速、轮上驱动力、车速、红线断油、拖挡和高挡起步熄火。
- **手动挡换挡过程**：按时间轴展示松油门、分离离合器、摘挡、选位、同步器摩擦同步、接合齿啮合以及重新接合离合器。
- **自动挡换挡原理**：展示液力变矩器、锁止离合器、TCU 换挡图、强制降挡及两排行星齿轮机构的执行元件组合。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 模型说明

手动变速箱使用齿数推导传动比，3D 齿轮与动力学模型共享参数。整车模型考虑发动机外特性、传动效率、主减速比、车轮半径、滚动阻力和空气阻力。自动挡模块使用液力变矩器特性曲线、带迟滞的升降挡图及行星排运动学关系。

该项目用于原理教学，不用于具体车型的工程标定或零部件强度计算。
